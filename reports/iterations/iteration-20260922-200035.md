- Decision: rejected and rolled back.

### Accepted: optimize nearby chairs query

- Evidence: Profiler reported `/api/app/nearby-chairs` as heavy: `110 req / total 115.916s / avg 1.054s / p99 2.812s` before this iteration.
- Previous shape: fetched all chairs, then ran ride/status/latest-location lookups per chair.
- Change: replace the N+1 loop with one SQL query that:
  - joins each chair to its latest location,
  - filters active chairs within the requested distance,
  - excludes chairs with incomplete rides.
